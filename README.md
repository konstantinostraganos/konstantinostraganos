## Konstantinos Traganos

I build machine learning systems for electricity grid problems. I work in operations monitoring at HEDNO, Greece's electricity distribution network operator, and I'm completing an MSc in Data Science at Deree, after a BSc in Statistics from AUEB.

### Featured projects

- **[greek-energy-forecasting](https://github.com/konstantinostraganos/greek-energy-forecasting)** — 24-hour electricity demand forecasting for Greece from ENTSO-E and Open-Meteo data. Seven models backtested on 89 daily cutoffs against the grid operator's own forecast; gradient boosting reaches 2.14% MAPE. MLflow, FastAPI, Streamlit, Docker, CI.
- **[movie-recommendation-system](https://github.com/konstantinostraganos/movie-recommendation-system)** — Top-N recommendation on MovieLens 25M with a strict temporal split. ALS reaches ~10× the Recall@10 of a popularity baseline. FastAPI and a live Streamlit demo.
- **[steam-reviews-nlp](https://github.com/konstantinostraganos/steam-reviews-nlp)** — Sentiment classification from TF-IDF baselines to fine-tuned DistilBERT (89.3% accuracy), explained with SHAP, plus a retrieval-augmented assistant over the reviews. Live demo.
- **[air-quality-monitor](https://github.com/konstantinostraganos/air-quality-monitor)** — Data pipeline from the OpenAQ API through dlt, DuckDB and dbt to a Streamlit dashboard, covering five European countries.
